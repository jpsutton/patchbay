# Benchmarks & routing — notes
Read 2026-11-10, index.

- Seminal AI, Benchmarks and leaderboards, https://seminal.ai/reference/categories/benchmarks-and-leaderboards/ — SWE-bench Verified 500 human-validated, heavily saturated 70-80%+, very high contamination; GPQA Diamond 198 Qs, saturated, frontier >65% PhD baseline; AIME saturated at frontier; prefer private/rolling held-out (HLE private, FrontierMath, MathArena fresh contests). Harness matters: 10-pt gaps collapse under same scaffold.
- Artificial Analysis Intelligence Index v5.0.1: 9 evals, 4 categories 25% each (knowledge work, coding, science, general); 60% weight private/held-out; versions not comparable across versions. Sources: https://www.scaler.com/topics/artificial-analysis-explained/ and https://www.iodigest.com/article/artificial-analysis-intelligence-index-v5-0-50269651
- LMArena / Aider: https://aiwiki.ai/wiki/llm_rankings — LMArena blind pairwise votes, Bradley-Terry, >5.7M votes / 330+ models May 2026, style/verbosity bias; Aider Polyglot 225 Exercism, 6 langs, 2 attempts, GPT-5 88% top, last updated 20 Nov 2025, high contamination.
- FrugalGPT arXiv:2305.05176, RouteLLM arXiv:2406.18665, Hybrid LLM — via https://www.justmalhar.com/blog/what-is-llm-routing/ and https://www.tmls.nyc/research/model-routing-cascades : FrugalGPT up to 98% cost cut at matched GPT-4 quality (cascade, learned scorer); RouteLLM >2x cut, 95% GPT-4 quality on MT-Bench routing only 14-26% to GPT-4; Hybrid LLM up to 40% fewer large-model calls.
- Routers: NotDiamond / Martian / OpenRouter Auto Router (NotDiamond meta-model) — https://dreaming.press/posts/2026-06-21-routellm-vs-notdiamond-vs-martian.html ; https://seangeng.com/writing/the-honest-guide-to-llm-routing — independent RouterArena/LLMRouterBench found no router optimal, one commercial router ranked 12th for over-selecting expensive models; honest production saving ~20-25% not 85-98%.
- Cursor Router / Claude Code: https://aq.dev/guides/model-routing-for-coding-agents-explained/ — Cursor Router ML classifier per agent request, Cost/Balance/Intelligence modes, cheapest model with comparable results; Claude Code has NO per-task router, only fixed opusplan split + fallback on overload.
